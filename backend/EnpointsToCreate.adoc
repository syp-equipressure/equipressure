= API Vordefinition
== Klassendefinition 

* Person
** eine Person hat eine oder mehrere Rollen
*** Unterklasse für Rolle (kein eigener Endpunkt später)
** persons/devices

* CustomerRelationship
** hat Id für Kunde
** hat Id für Sattler
** hat boolean für isFavourite (einziger Grund warums die Klasse gibt)
** hat boolean für isContact

* Devices
** hat Person Besitzer
** hat List<Person> Nutzer
** hat DeviceCategory Id
*** Unterklasse DeviceCategory
** devices/persons


== Endpunkte

Personen:

* GET /persons => alle Personen
* GET /persons/:id => Person mit id :id
* GET /persons/:id/contacts => Kontakte einer Person
* GET /persons/:id/favourites => Favourisierte Sattler einer Person
* GET /persons/:id/devices => alle Geräte einer Person
** könnte eventuell boolean liefern ob Person Owner ist
* GET /persons/:id/horses => alle Pferde einer Person
* GET /persons/saddlers/locations => alle Sattler mit Person_Id, Name und location
* GET /persons/:id/horses/locations => alle Pferde mit Pferde_Id, Location, Profilbild einer Person
* GET /persons/:id/location => Location einer Person mit id :id

Locations:
* POST /locations => add a location

Geräte:

* GET /devices/:personId => alle Geräte einer Person
* GET /devices/:id => Gerät mit der id :id
* GET /devices/:id/owner => Besitzer des Gerätes (Person)
* GET /devices/:id/users => alle Personen eines Geräts
* POST /devices => neues Device hinzufügen
* PUT /devices/:id => neuen User zu Gerät hinzufügen/löschen
* DELETE /devices/:id => Gerät mit einer id: löschen
* PATCH /devices/:id/owner => neuen Besitzer festlegen

Pferde: 

* GET /horses/:personId => alle Pferde einer bestimmten Person
* GET /horses/:id => Pferd mit id :id
* GET /horses/:id/saddles => alle Sättel eines Pferdes
* GET /horses/:id/persons => Reitbeteiligungen + Owner
** Owner entweder an erster Stelle oder eigener Endpoint für Owner
** eventuell /horses/:id/owner
* GET /horses/:id/hidden/persons => Hidden user

Messungen:
(mg.. measurementgroup)

* GET /measurementgroups/:horseId => Alle Messungsgruppen eines Pferdes
** minimale Daten: Datum, Person die durchgeführt hat, Sattel mit dem durchgeführt wurde
* GET /measurementgroups/:mgId => Detailansicht für eine Messungsgruppe
** alle Daten: Pferd (mit Name, Rasse, Alter, Gewicht), Reiter (mit Name, Größe, Gewicht), Sattel, Datum, Notizen
* GET /measurementgroups/:mgId/measurements => Alle Messungen aus einer Gruppe
* GET /measurementgroups/:mgId/measurements/average?pace=&hand= => Durchschnitt aller Messungen einer Gruppe
** query paramter: pace/Gangart und Hand optional filtern könnena
* GET /measurementgroups/:mgId/measurements/min?pace=&hand= => Minimum aller Messungen einer Gruppe
* GET /measurementgroups/:mgId/measurements/max?pace=&hand= => Maximum aller Messungen einer Gruppe
* GET /measurementgroups/:mgId/measurements?pace=&hand= => Eine Messung aus einer Messungsgruppe
** wir suchen nicht mehr nach TeilmessungsId sondern filtern nach pace und hand, da sie eindeuting sein müssen
* GET /measurementgroups/:mgId/measurements/:mId/measurementData/ => Alle Messdaten aus einer Messung; alle Daten für alle Timestamps
* GET /measurementgroups/:mgId/measurements/:mId/measurementData/:dId => Ein Messdatum aus einer Messung nach id; alle Daten für ein Timestamp
