= API Vordefinition
== Klassendefinition 

* Person
** eine Person hat eine oder mehrere Rollen
*** Unterklasse für Rolle (kein eigener Endpunkt später)
** persons/devices

* CustomerRelationship
** hat Id für Kunde
** hat Id für Sattler
** hat boolean für isFavourite (einziger Grund warums die Klasse gibt)
** hat boolean für isContact

* Devices
** hat Person Besitzer
** hat List<Person> Nutzer
** hat DeviceCategory Id
*** Unterklasse DeviceCategory
** devices/persons


== Endpunkte

Personen:

* /persons => alle Personen
* /persons/:id => Person mit id :id
* /persons/:id/contacts => Kontakte einer Person
* /persons/:id/favourites => Favourisierte Sattler einer Person
* /persons/:id/devices => alle Geräte einer Person
** könnte eventuell boolean liefern ob Person Owner ist
* /persons/:id/horses => alle Pferde einer Person

Locations:


Geräte:

* GET /devices/:personId => alle Geräte einer Person
* GET /devices/:id => Gerät mit der id :id
* GET /devices/:id/owner => Besitzer des Gerätes (Person)
* GET /devices/:id/users => alle Personen eines Geräts
* POST /devices => neues Device hinzufügen
* PUT /devices/:id => neuen User zu Gerät hinzufügen/löschen

Pferde: 

* /horses/:personId => alle Pferde einer bestimmten Person
* /horses/:id => Pferd mit id :id
* /horses/:id/saddles => alle Sättel eines Pferdes
* /horses/:id/persons => Reitbeteiligungen + Owner
** Owner entweder an erster Stelle oder eigener Endpoint für Owner
** eventuell /horses/:id/owner
* /horses/:id/hidden/persons => Hidden user

Messungen:
(mg.. measurementgroup)

* /measurementgroups/:horseId => Alle Messungsgruppen eines Pferdes
* /measurementgroups/:mgId/measurements => Alle Messungen aus einer Gruppe
* /measurementgroups/:mgId/measurements/average => Alle Messungen aus einer Gruppe
* /measurementgroups/:mgId/measurements/min => Alle Messungen aus einer Gruppe
* /measurementgroups/:mgId/measurements/max => Alle Messungen aus einer Gruppe
* /measurementgroups/:mgId/measurements/:mId => Eine Messung aus einer Messungsgruppe
* /measurementgroups/:mgId/measurements/:mId/measurementData/ => Alle Messdaten aus einer Messung
* /measurementgroups/:mgId/measurements/:mId/measurementData/:dId => Ein Messdatum aus einer Messung nach id
