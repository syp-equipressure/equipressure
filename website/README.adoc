= EquiPressure Website

Statische Website (HTML, CSS, JS) zur Vorstellung von EquiPressure.

== Lokal ansehen

Braucht nur Node.js, es wird nichts installiert.

[source,bash]
----
cd website
npm start
# http://localhost:8000
----

== Aufbau

[cols="1,3"]
|===
|Datei |Inhalt

|`index.html`
|Die ganze Seite: Hero, Problem, Lösung, Ablauf, Zielgruppen, Messung, Mehrwert, Preise, Team, FAQ

|`css/styles.css`
|Farben und Stil wie in Reiter-App und Sattler-Frontend, inklusive Dark Mode

|`js/main.js`
|Handy-Menü und Jahreszahl im Footer

|`assets/img/`
|Logo, App-Screenshots und Team-Avatare aus der Präsentation
|===

== Preise

Kaufen kann man über die Website noch nicht, bei den Preisen steht „Bald erhältlich“.
Die Preise stehen in `index.html` im Abschnitt `#preise`.
